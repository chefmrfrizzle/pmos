# David Rothschild Demo — Private Sales OS

Build one polished synthetic transaction.

## Story

A £18M contemporary artwork is offered for discreet private sale.

### 1. Asset dossier

- artist / work / date / medium / dimensions
- indicative value
- jurisdiction
- custody
- legal owner and authority to sell
- provenance timeline
- supporting evidence

### 2. Evidence engine

Classify:

- PASS
- PASS — EXCEPTIONS
- INSUFFICIENT EVIDENCE
- PROVENANCE REVIEW
- RESTITUTION REVIEW
- ATTRIBUTION REVIEW
- CULTURAL PROPERTY REVIEW
- EXPORT REVIEW
- COUNSEL ESCALATION

### 3. Transaction readiness

Show a single readiness score with the components beneath it:

- identity
- authority to sell
- beneficial-ownership verification
- provenance completeness
- condition
- valuation freshness
- sanctions/KYC status
- restitution
- export/import
- evidence confidence

### 4. Buyer-fit engine

Use only synthetic collector/family-office profiles.

Score:

- artist affinity
- price fit
- geography
- acquisition timing
- collection gap
- relationship strength
- discretion preference

The output is not “9,000 rich people.” It is “the seven relationships worth discussing for this asset.”

### 5. Exhibition intelligence

Because David's remit includes private-sales exhibitions, show:

- candidate works
- qualified relationship density
- invited / attending
- private appointments
- active negotiation count
- transaction-readiness by work
- recommended next action

### 6. Deal room

Evidence → approvals → logistics → export → payment milestones → close → relationship graph update.
